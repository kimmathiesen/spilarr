Windows-hjælper

Knapperne Installer, Afmonter og Åbn mappe er spil://-links. De virker på en Windows-PC med hjælperen installeret: den mounter ISO'en direkte fra sharen (intet kopieres) og åbner drevet i Stifinder.

Installation (én gang pr. PC, ingen administrator)

Kør i PowerShell:

irm {{ server }}/windows/install.ps1 | iex

Den lægger spil-handler.ps1 i %LOCALAPPDATA%\Spilarr og registrerer spil:// for din bruger (HKCU).

Første gang

  • Windows skal kunne nå sharen: åbn den i Stifinder og gem login.
  • Browseren spørger, om den må åbne Spilarr-links – vælg Tillad altid.

Se spil-handler.ps1 · Se install.ps1

Linux-hjælper

Samme knapper på Linux (fx CachyOS eller steam-headless). ISO'er mountes med udisksctl eller – i containere uden loop-enheder – med fuseiso/archivemount. .exe-filer køres med Proton via umu-run (ellers wine) i ét prefix pr. spil under ~/Games/spilarr/.

Installation (én gang pr. bruger, ingen root)

curl -fsSL {{ server }}/linux/install.sh | sh

Den finder selv spilmappen (/mnt/torrents i steam-headless, /mnt/spil eller et gio-mount af smb://…/data). Angiv den ellers som argument: … | sh -s -- /sti/til/games. Indstillingen ligger i ~/.config/spilarr.conf.
