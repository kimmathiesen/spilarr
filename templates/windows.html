Windows-hjælper

Knapperne Installer, Afmonter og Åbn mappe er spil://-links. De virker på en Windows-PC med hjælperen installeret: den mounter ISO'en direkte fra sharen (intet kopieres) og åbner drevet i Stifinder.

Installation (én gang pr. PC, ingen administrator)

Kør i PowerShell:

irm {{ server }}/windows/install.ps1 | iex

Den lægger spil-handler.ps1 i %LOCALAPPDATA%\Spilarr og registrerer spil:// for din bruger (HKCU).

Første gang

  • Windows skal kunne nå sharen: åbn den i Stifinder og gem login.
  • Browseren spørger, om den må åbne Spilarr-links – vælg Tillad altid.
